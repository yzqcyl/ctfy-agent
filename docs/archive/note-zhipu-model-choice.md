> 数据来源：智谱官方文档（模型概览 / API 定价，2026-10-30 抓取）。

## 2. 选型逻辑（只认我们自己的实测数据）

- 历史单题消耗 ≈ **292k tok/解出**（15.33M / 35 题口径见报告 §10）；1B 额度 ≈ 可支撑 **3,000+ 题次**；
  正式赛题量远小于此 → **token 额度不紧，质量优先**，不该为省钱选弱模型。
- 思考模式：GLM-5.3 系**强制思考不可关闭**（与用户 10-30 决定一致：不关思考）；思考 token 计入输出——
  选型时关注「单题解决率」而非单价，必要时用 max_tokens 余量兜底（当前 8192，观测到空回答再调）。
- **结论：首选 GLM-5.3**；若平台上该模型排队/限流严重，降级 **GLM-5.3-FlashX**（快、便宜、同代）；
  GLM-5.3-Flash 作为「额度异常紧张」时的兜底。**不选 5.2 及更老**（同样价格、更弱）。

## 3. 待平台确认项（评测/正式赛前逐条核）

1. 平台 LLM 通道是否 OpenAI 兼容、base_url 是否为 `https://open.bigmodel.cn/api/paas/v4`（我们容器只发 openai 方言）；
2. 官方额度**按什么计量**：是否含思考 token、是否按缓存命中价折扣（影响 max_tokens 与上下文压缩策略的取舍）；
3. 模型名在平台侧的准确字符串（`glm-5.3` / `glm-5.3-flash` 还是带版本号）；
4. 是否有速率限制（RPM/TPM）——有则需要在 `llm.py` 加重试/退避（已有 1 次重试，可能不够）。

## 4. 与现有决策的关系

- 与「不关思考」一致：选型不依赖关闭思考字段；
- 与 v4 镜像无关：模型是平台侧配置，镜像里不需要改；
- 若待确认项 2 表明「思考 token 也全额计入 1B」，再评估 max_tokens 余量与压缩策略（属 v4 之后的调整）。
