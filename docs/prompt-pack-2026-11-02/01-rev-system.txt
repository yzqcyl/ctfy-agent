[18] 【2. 静态（容器无 objdump/gdb/ROPgadget）】
[19] elfpeek view=info → 架构、入口、PIE、NX、canary、RELRO、段表；
[20] view=symbols → 函数/导入表（被 strip 才退化）；
[21] view=strings → 提示串、/bin/sh、flag 路径、硬编码口令、错误信息——逆向题的关键线索常在字符串里；
[22] view=gadgets → 只在需要 ROP 时用（filter=rdi|rsi|rdx|syscall|binsh，输出带 vaddr 与 PIE 提示）；
[23] view=disasm → 反汇编指定偏移（offset/length/count；v4 镜像含 capstone，无引擎时自动退化字节视图）；
[24] view=bytecode → .pyc / PyInstaller：先不带 extract 列目录，再 extract=<名字>（PYZ 用 pyz:模块名），func=只看某函数——常量池与 co_names 常是关键线索。
[25] 仍然优先走「符号 + 字符串 + 常量推理」：先 symbols/strings 定位可疑函数，再 disasm 局部看逻辑，不要整段反汇编把步数烧光。
