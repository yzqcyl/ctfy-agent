# 03 · 提示词是怎么拼起来的（改之前必须懂这个）

模型实际收到的 system message **不等于** `01`/`02` 里的正文，而是：

```
最终 system = 正文（你改的部分）
            + [条件追加] COMPANION_RULE   ← 只有正文不含 "PLAN" 时才加
            + [条件追加] EVIDENCE_RULE     ← 只有正文不含 "evidence"（小写比较）时才加
            + [条件追加] HANDOFF_RULE      ← 只有正文不含 "report" 时才加
            + [无条件追加] UNAVAILABLE_RULE
```

拼接逻辑在 `src/ctfy_agent/crew.py::_role_system`（第 648–660 行），判定是**朴素子串匹配**，不是语义判断。

## 当前两个角色的实际情况（实测）

| 角色 | 正文长度 | 含 `PLAN` | 含 `evidence` | 含 `report` | 实际追加 | 最终长度 |
|---|---|---|---|---|---|---|
| rev | 2223 字符 | ❌ 否 | ✅ 是 | ✅ 是 | COMPANION + UNAVAILABLE（230 字符）| 2453 |
| pwn | 2235 字符 | ❌ 否 | ✅ 是 | ✅ 是 | COMPANION + UNAVAILABLE（230 字符）| 2465 |

## 四条追加规则的逐字原文

**COMPANION_RULE**（rev/pwn 目前都会追加）
```
输出格式：每次回复先在文本里写两行标签，再调用工具——
PLAN: 当前计划，一句话；计划没变就原样复制上一轮那句，不要改措辞。
REFLECTION: 上一步结果说明什么、这一步为什么这么做，一句话。
```

**EVIDENCE_RULE**（rev/pwn 目前不追加，因为正文已含 evidence）
```
结论纪律：交付结论时，evidence 字段必须从某一次工具输出里**原样复制**一段连续字符（不要改写、概括或翻译）；声称「发现/拿到/绕过」却不给逐字证据的结论会被打回重交。
```

**HANDOFF_RULE**（rev/pwn 目前不追加，因为正文已含 report）
```
交付规则：结论必须用 report 交出去（调用即结束回合，协调者才看得到）；note 只用来记中间线索，不要拿它交付结论。
```

**UNAVAILABLE_RULE**（无条件追加，every time）
```
不可达纪律：目标 DNS 解析失败 / 连接被拒 / 超时时，最多换一种接入方式再试一次，仍失败就**立刻交付卡点**（写清 host:port 与错误原文，不要空转）；严禁转而浏览本地文件系统、源码目录或系统路径去找线索——那不是本题解法，只会浪费预算。
```

## ⚠️ 三条红线（违反会导致静默故障，测试不会报错）

1. **不要在新提示词里出现 `PLAN` 这个词。**
   一旦出现（哪怕是在说"PLAN 阶段"），COMPANION_RULE 就不再追加，模型不再输出 `PLAN:` / `REFLECTION:`，
   而下游 `companion.PlanTrack` 依赖这两个标签解析计划变化 —— A2 计划跟踪功能会**静默失效**。

2. **不要删掉正文里的 `evidence` 和 `report` 两个词。**
   删了会触发对应规则追加。追加本身不算错，但会造成**同一段纪律在提示词里出现两遍**（正文一遍、追加一遍），
   白烧 token 且容易让模型把两处措辞当成两个不同要求。

3. **UNAVAILABLE_RULE 是无法关闭的，所以正文里不要再重复写一遍"不可达就收口"。**
   rev 正文第 12 行、pwn 正文第 12 行现在各有一句"DNS 失败=本机无隧道，直接 report 卡点"，
   与自动追加的 UNAVAILABLE_RULE 语义重复。这是**现存冗余**，可以在本次改动中顺手合并
   （但保留正文那半句，因为它带了具体工具名 netcheck，追加版没有）。

## 一条硬约束：提示词不能超过预算

上下文窗口 32000 tokens，单题预算 1,200,000 tokens / 100 次调用。提示词每加 100 字符，
按 14 步算就是每步多 ~25 token，单题多 ~350 token —— 相比 1.2M 微不足道。
**所以长度不是硬约束，注意力才是。** 现有 rev 正文 2223 字符 / 41 行，已经是"扫一眼就要花力气"的密度；
再加内容必须**等量删减**，不要再堆"第 N 条注意事项"。
