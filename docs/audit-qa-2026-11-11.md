## 0. 三句话结论

1. **协议已升到 v3，是 breaking change**：平台**替你起好实例**（`task.json` 给 `target_instance` /
   `target_endpoints`），`POST /api/v1/instances` 现在**恒 403**，token **只能读/交本题**。
   我们只有部分适配（11-03 实测过 SAMPLE-004 的预下发），`schema_version` 还写着 **2**。
2. **「重跑」不用自己造了**：v3 §3.3 明确平台会在**同一工作目录、同一靶场**上把你的镜像**再启动，最多 5 轮**——
   触发条件是「新题号解锁」或「交错了但该题还有次数」。所以我 11-10 说的「做不到重跑」正式作废，
   需求 3 的标注/续跑正好对上这套机制。
3. **QA「VPS 常驻轮询」（#77/#81）与协议 v3 不冲突——它们是两种部署形态**（2026-11-11 复审订正，
   原判「冲突、以协议为准」过于绝对）：
   - **平台托管 harness**（协议 CTFY-0001 v3 管的形态）：平台按题起容器、发 `task.json`、
     per-run token 只认本题。**入围测试 11-14 / 初选赛 11-15 用这套**（平台赛事已配 11-15 的
     solve sessions；我们的 SAMPLE harness 跑法就是它）。
   - **VPS 常驻**（QA #5/#6/#16/#24/#49/#77/#81 描述的形态）：4C8G VPS、常驻进程自己轮询拉题、
     3 次重启、保存工作目录。QA #82「进入正式赛的队伍，在正式赛赛前重新部署智能体」指向
     **正式赛 11-21/22 用这套**（届时是队伍级账号，token 语义不同，v3 的单题限制不适用）。
   - 结论：**11-15 前不需要常驻调度器**（A1–A4 是关键路径）；**11-16~20 必须做出题 + 常驻调度**
     （G7 一并做）。G9 兜底分支仍值得做（半天），把「形态判断错」的尾部风险买掉。

## 1. 平台协议 v3 对齐（P0，可测）

### 1.1 v3 到底改了什么（原文要点，`standards-live/CTFY-0001.md`）

| 变更 | 原文要点 | 我们的状态 |
|---|---|---|
| 预启实例 | 「Every run with a target gets `target_instance` in `task.json`, and the target **is already running** when you start」；`POST /api/v1/instances` → **403 `token_missing_scope`** | ✅ 11-03 已实测适配（`agent_main.py:339-345` 置 `instance_preissued`，solver 禁自启）；⚠️ 恢复/清场路径仍会调 `start_instance`/`list_instances`，需确认在预下发时被完全短路 |
| token 作用域 | 「The run's token **reads and submits for the run's own challenge only**」，其它题 → **403 `token_challenge_forbidden`** | ✅ 复审订正：`_evict_stale_instances` 只在 **429 容量错误**分支可达，v3 下 `start_instance` 调不通（预下发短路），**实际不可达**。真正的缺口是**自愈路径**（`solver.py:623` 只查 `auto_start_instance`，不查 `instance_preissued`）：实例死标记触发时会调 `start_instance` 撞 403（被 `instance_recover_limit=2` 钳制），且文案「平台未能重建实例」在 v3 下是误导——实例生命周期归平台管，我们无能为力，应引导收口 |
| `schema_version` | 3 | ❌ **我们是 2**（`agent_main.py:37`）。复审降级：v3 明说该字段**可选**、不写只是 conformance 检查的 **advisory**，不是拒收；但 §3.2 要求「write it」，且写旧版号会在下次 breaking 时无法诊断。照改（10 分钟），**不是紧急项** |
| `target_endpoints` / `CTFY_TARGET_URL` | 已发布地址列表；恰好一个 web 端点时给 `CTFY_TARGET_URL`，「an agent need not call the platform to find its target」 | ✅ 已读 `target_endpoints`（`agent_main.py:141,395`）；`CTFY_TARGET_URL` 未用但无害 |
| 附件 | 平台预先把**本题自己的副本**放 `/ctfy/work/attachments/`，`task.json.attachments[]` 列名/大小/`path`；`path: null` 表示**单次拷贝上限 4 MiB** 未拷贝，需 `GET /api/v1/instances/{target_instance}/attachments/{name}` 自己下 | ❌ 复审确认**是坑且比预想严重**：`agent_main.py:413` 把 `path:null` 转成空串，提示语变成「附件已就位：（直接读本地文件，**不要调下载接口**）」——**主动误导模型**，>4MiB 附件题直接 0 分。修法：`path` 为空时改写提示为「未拷贝（>4MiB），用 GET /api/v1/instances/{id}/attachments/{name} 下载」 |
| 退出码语义 | **只看退出码**：`0` = 跑完（解没解出都算完成）；非 0 = 崩溃（原因取 stderr 末尾）。**没写 result.json 不再算失败**；stdout 里打印 `FLAG{...}` 不计分 | ✅ 我们恒 `return 0`（`main` 兜底） |
| 必须调用模型 | 「A hosted run that exits `0` having made **no** call to `LLM_BASE_URL` is recorded `errored`」 | ⚠️ 我们的 `refused`（未知 run_mode、缺凭证、flavor 不符）路径**不调模型就退出** → 会被记 `errored`。分数本来就是 0，但状态难看；低优先 |
| 轮次 | 最多 **5 轮**，同工作目录、同靶场；`result.json` 每轮**重写**；下一轮 `README.md` 给每题判定（correct/wrong/not answered/newly unlocked），**不重复已交过的值**；「No round starts with less than a minute left, after a non-zero exit, once everything visible is solved」 | ✅ 复审确认**状态跨轮真实成立**：`agent_main.py:318` 把 `runs_dir` 覆盖为 `$CTFY_WORK_DIR/runs`（**在 v3 保留区内**），`run_id = challenge_id` 跨轮稳定，第 2 轮 `Store.load()` 能接上第 1 轮的错答台账（`reserve_submit` 的 duplicate 拦截同值重交）。原审计 G3「runs 不在 work 目录」**有误**（该覆盖 11-03 已加）。剩 A4 用例钉死即可 |
| dry run | 干净退出**或**写了文件即通过；都不做才算失败 | ✅ 已兼容 |

### 1.2 必须改的四件事（按性价比排序）

| # | 改动 | 为什么现在改 | 工作量 |
|---|---|---|---|

> G9 兜底分支（无 task.json 不 halted）仍做，半天，对冲形态判断错误的尾部风险。

### 1.3 「重跑」结论修正

| | 11-10 的说法 | v3 之后 |
|---|---|---|
| 一个容器一题 | 对 | 仍对，但**同一题会被重启最多 5 轮** |
| 我们主动重跑 | 做不到（调度权在平台） | **不需要**：平台在「新题号解锁 / 错答可重试」时自己重开，且工作目录保留 |
| 需求 3 的价值 | 标注 + 侧车 + 续跑（退而求其次） | **标注与续跑直接变成主线**：每轮都要能接上上一轮的 `state.json`，`result.json` 必须每轮重写 |

## 6. 一句话

**真正要命的不是形态，是 v3 的四个细节**：平台已经替你起好实例（别再去 `POST /instances`）、
token 只认本题（自愈别再指望重建）、`schema_version` 写 3（advisory 但照写）、`result.json` 每轮重写。
其中**已被复审证实的硬坑是附件 `path:null` 的误导提示**（A3）和**自愈路径的 403+误导文案**（A2），
这两处今天就能修完。
「VPS 常驻轮询」不是与 v3 冲突，而是**正式赛的另一种形态**——11-15 前不碰，11-16~20 与出题一起做（G10）。
