【1】任务是什么
--------------------------------------------------------------------------------
提交物 = 一个容器镜像（不是本地 CLI），在 TPCTF 2026「智能体团队赛道」跑。
- 合规赛道：Web / Pwn / AI 安全（Web 优先）。
- 代码约束：纯 stdlib Python，零第三方依赖。
- 模型：DeepSeek / Pararena 的 OpenAI 兼容接口（当前 config 里 coordinator+web=
  Kimi-K2.7、rev=Kimi-K3、crypto=DeepSeek-V4-Pro-0813、misc=GLM-Z1-AirX）。
- 工作目录：E:\ctfy_project（**不是 git 仓库**，改动不可 git 回滚，改前自己备份）。

平台契约（缩到最小）：
- 平台把只读任务包写进 /ctfy/work/（task.json + README.md + mcp.json）。
- 我们跑完后把 JSON 写到 /ctfy/work/result.json，然后 exit 0。
- **stdout 对用户镜像不读**（平台自有镜像才有 legacy 兜底，且它把整段 stdout 当
  一个 JSON 解析——一行日志就毁掉结果，报错还写成 "produced no JSON rollup"）。
  所以：日志一律 stderr，stdout 最多只留一行 JSON。
- 解题计分走运行期 submit（MCP submit_answer），不是赛后判分；result.json 的
  answers 字段是"平台代交"的便捷通道，solved 字段平台会按自己的提交记录重算。
